# Agent documentation

The root `AGENTS.md` is the entry point for automated coding tools. This folder holds stable rules that are too detailed for that file.

- `CODE_CHANGE_RULES.md` — scope, boundaries, implementation, and validation
- `SECURITY_RULES.md` — authentication, authorization, commerce, media, and secrets
- `DOCUMENTATION_RULES.md` — which documents to update and how to keep claims verifiable

Read only the documents relevant to the requested change. Human explanations live under `docs/human/` and in the root-level architecture and decision records.
